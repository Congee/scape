# Bundled eclipse elements

- `besselian.json`: polynomial Besselian elements of every solar eclipse 2000–2100 from NASA's Five Millennium Canon of Solar Eclipses (Espenak and Meeus, NASA GSFC, https://eclipse.gsfc.nasa.gov/SEcat5/beselm.html), public domain. Built by `scripts/build-eclipses.ts`; loaded lazily by the calendar's eclipse detail.
